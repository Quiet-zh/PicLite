# PicLite 图轻 v1.8.9

- 修正 Windows 悬浮窗复制优化结果的文件体积问题：复制 WebP、JPEG、PNG 等结果时直接写入实际压缩文件，不再以无压缩位图传递给目标应用。
- Windows 目标应用粘贴后会收到 PicLite 生成的原始编码与文件扩展名，避免 143 KB WebP 被聊天软件重新保存成 810 KB PNG 一类的体积膨胀。
- Windows 文件剪贴板写入会先清除残留位图，并在剪贴板被占用时自动重试三次。
- 如果系统无法复制结果文件，悬浮窗会明确提示失败，不再静默回退为体积更大的 PNG 位图。
- 保留复制前屏蔽 PicLite 自身剪贴板监听的处理，避免复制结果再次触发自动压缩。

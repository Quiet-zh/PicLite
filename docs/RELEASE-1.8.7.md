# PicLite 图轻 v1.8.7

- 新增内置“格式转换”和“尺寸调整”插件；插件默认隐藏，可在设置中按需开启，不占用主界面导航空间。
- 格式转换支持 JPEG、JFIF、PNG、WebP、AVIF、GIF、BMP、TIFF、ICO、QOI、TGA，并允许为转换结果单独选择输出位置。
- 尺寸调整支持按比例缩放、指定宽高和扩图，也可将结果保存到原图目录或自定义文件夹。
- 格式转换、尺寸调整和批量重命名可在各自插件页面直接建立文件夹监测任务，无需跳转后重新配置。
- 修复尺寸调整后的图片再次复制压缩时重复缩放、格式切换后体积反而增大的问题；切换格式时会以当前结果为基准，并保留体积更小的结果。
- 改进插件与文件夹监测的运行逻辑：隐藏入口不会停止已启用的后台监测任务，并补充格式编码、结果基准与体积保护回归测试。
